洛克王国自动孵蛋工具 使用说明
=================================

版本: v1.3
日期: 2026-05-14

适用环境
--------
- Windows 10 / 11 (64-bit)
- 《洛克王国：世界》窗口化模式，保持在孵蛋界面
- 屏幕设置二选一：
    - 2560 x 1440，缩放 125%
    - 1920 x 1080，缩放 100%

安装步骤
--------

第一步：解压
  将压缩包解压到任意目录。

第二步：安装 Interception 驱动（仅首次，需管理员权限）
  1. 右键 install-interception.exe，选择「以管理员身份运行」
  2. 安装完成后重启电脑
  3. 重启后，在命令行输入以下命令验证驱动已加载：
       sc query interception
     若显示 STATE: 4 RUNNING 则安装成功。

  > 如果 install-interception.exe 无法运行，请从以下地址下载最新版：
  > https://github.com/oblitum/Interception/releases
  > 解压后以管理员身份运行 command line installer/install-interception.exe。

第三步：安装 VC++ 运行时（如已安装可跳过）
  若启动时提示"缺少 VCRUNTIME140.dll"，请安装：
  https://aka.ms/vs/17/release/vc_redist.x64.exe

使用步骤
--------
1. 启动游戏，设置为窗口化模式，进入孵蛋界面
2. 双击 roco_auto.exe 打开程序
3. 在「屏幕设置」下拉框选择与你当前屏幕匹配的选项
4. 在「选择目标蛋」下拉框选择蛋种，点击「+ 加入队列」；可加入多个蛋种，用上下箭头调整顺序
5. 在「选择咕噜球」下拉框选择契约所用的咕噜球
6. 点击「启动」

程序将自动循环执行：放蛋 -> 等待孵化 -> 契约。日志面板实时显示运行状态。

注意事项
--------
- 运行中请勿移动游戏窗口，否则程序无法定位 UI 元素
- 屏幕缩放比例不可更改，否则模板匹配将失效
- 可随时点击「停止」中断运行（最长延迟 2-8 秒）
- 工作流结束后可选自动关闭游戏窗口或自动关机
- 每次工作流结束，日志自动保存至 logs/ 目录
- 如需调整队列，请先停止运行

常见问题
--------
Q: 启动时提示"未找到 interception.dll"？
A: 请确认 interception.dll 与 roco_auto.exe 在同一目录。

Q: 启动后提示"驱动上下文创建失败"？
A: Interception 驱动未安装或未重启，请完成第二步后重试。

Q: 点击「启动」后提示"窗口未找到"？
A: 确保游戏已启动、窗口化、处于孵蛋界面。可点击「测试匹配」检查当前屏幕下的模板匹配度。

Q: 匹配度普遍偏低？
A: 请检查屏幕设置下拉框是否匹配当前屏幕分辨率和缩放比例。
